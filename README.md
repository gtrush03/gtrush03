Founder of **TRU Synth**, where I build autonomous agent infrastructure: multi-agent orchestration, LLM-powered automation pipelines, and AI systems that operate independently. I've shipped **20+ products in 8 weeks** using AI-native development with Claude Code, winning multiple NYC hackathons along the way. ## What I Build

### AI Agent Systems
Multi-agent orchestration platforms where autonomous agents collaborate, make decisions, and execute complex workflows. I work across the full agent stack — from Claude API and Gemini API integration to MCP server architecture, agent memory systems, and tool-use pipelines. My agents don't just chat — they trade, scout, research, and deploy.

### AI-Native Products
I ship at extreme velocity by building with AI as a first-class collaborator. 20+ repositories, 35+ Vercel deployments, full-stack products built in 48-hour hackathon sprints. My stack is optimized for speed: React 19, Vite, Supabase, and Claude Code as the core development engine.

### Spatial AI & Robotics
AI agents that inhabit 3D worlds — photorealistic Gaussian splat environments with autonomous characters, MuJoCo WASM robotics simulations with Gemini vision, and gesture-tracked interfaces where you interact with AI through physical movement.
